# Автозагрузка с iPhone через «Быстрые команды»

Мини-приложение не может само заглянуть в галерею телефона — так устроены iPhone. Зато встроенное приложение
**«Команды»** умеет находить фото и отправлять их на наш сервер. Настраивается один раз, дальше работает само.

**Как это работает:** команда «Фото в Telegram» спрашивает у сервера задание — с какой даты искать фото,
куда и как их отправлять, — находит до 100 фото и отправляет по одному. Сервер кладёт их в ваш чат с ботом,
и они появляются в галерее. Всё, что можно настроить (оригиналы или сжатые, загружать ли старые фото),
меняется в галерее — саму команду трогать не нужно. Если запуск сорвался, ничего не теряется: следующий
начнёт с того же места. Одно и то же фото дважды не загрузится. Скриншоты и видео не загружаются: их отсеивает
сам сервер (фильтры «Команд» на iOS 26 срабатывают не всегда). Если iPhone зависает на каком-то снимке, сервер
его пропустит, а бот напишет его дату.

## Обычный способ: готовая команда

В галерее: **«…» → «Автозагрузка с iPhone» → «Подключить автозагрузку» → «Добавить команду»**. Ключ
скопируется сам; когда iPhone спросит его, нажмите на поле → «Вставить» → «Добавить команду». Потом
сделайте автоматизацию — шаги показаны там же, на экране. И один раз включите «Настройки» →
«Приложения» → «Команды» → «Дополнительно» → **«Разрешить отправку больших объёмов данных»**: без этого
iPhone отправляет только одно фото за запуск.

Если кнопки «Добавить команду» нет, значит, владелец бота ещё не сделал готовую команду. Тогда соберите её
сами по инструкции ниже — или, если вы владелец, соберите и поделитесь ею ссылкой (раздел в конце).

## Собрать команду самому

> Названия действий даны так, как они выглядят на iPhone с русским языком, в скобках — по-английски.
> В поиске действий можно вводить любое из них. Это команда **версии 2**: она перед каждым снимком спрашивает
> сервер, брать ли его, и сообщает, через какую сеть подключена и что запуск закончен.

**Три правила, без которых не заработает** (проверено на iOS 26):

- Каждое новое действие само берёт на вход результат предыдущего. Всегда проверяйте входы: нажмите на
  значение → **«Очистить»** (Clear) → **«Выбрать переменную»** (Select Variable) → нужная плашка.
- Значения выбирайте **переменными** (цветная плашка со значком), а не набирайте словами.
- В заголовках не должно быть пустых строк «Key — Text»: с ними Cloudflare отвечает «400 Bad Request».

Перед началом: «Настройки» → «Приложения» → «Команды» → «Дополнительно» (Advanced) → включите
**«Разрешить отправку больших объёмов данных»** (Allow Sharing Large Amounts of Data). Без этого iPhone
остановит команду на втором фото с ошибкой «trying to share … Photos items, which is not allowed».

В галерее: **«…» → «Автозагрузка с iPhone» → «Подключить автозагрузку»**. Появятся **ключ** и **адрес
задания**. Ключ показывается один раз.

Приложение «Команды» → **«+»**. Сразу переименуйте команду (название вверху → «Переименовать») в
**«Фото в Telegram»**. Добавьте действия по порядку.

**Задание от сервера**

1. **«Текст»** (Text): вставьте **ключ** целиком, вместе со словом `Key`. Ровно одна строка, без пробелов
   и пустых строк после ключа.

2. **«Получить сведения о сети»** (Get Network Details): сеть **«Wi‑Fi»**, сведения **«Имя сети»** (Network Name).

3. **«Если»** (If): «Сведения о сети» → **«имеет любое значение»** (has any value).
   - Между «Если» и «Иначе»: **«Текст»** `wifi`.
   - Между «Иначе» и «Конец если»: **«Текст»** `cell`.

4. **«Получить содержимое URL»** (Get Contents of URL)
   - URL: **адрес задания** (заканчивается на `/api/auto/next`), сразу за ним допишите `?v=2&net=` и добавьте
     переменную **«Результат „Если“»** (If Result) из шага 3.
   - Заголовки (Headers) → добавить: ключ `Authorization`, значение — переменная **«Текст»** (шаг 1).
     Внимательно: iPhone любит исправлять слово на «Authorisation» — нужно через **z**.

5. **«Получить значение словаря»** (Get Dictionary Value): ключ `ago`, вход — «Содержимое URL».
   Затем **«Изменить дату»** (Adjust Date): **«Вычесть»** (Subtract) · «Значение словаря» · **секунд**
   (seconds) · из **«Текущая дата»** (Current Date). Если поле даты занято переменной — «Очистить переменную»,
   нажмите на пустое поле ещё раз и выберите «Текущая дата».

6. **«Найти фото»** (Find Photos). Если действие превратилось в «Фильтр … где» (Filter … where) — нажмите
   на подставленное значение → «Очистить».
   - Фильтр **«Дата создания»** (Creation Date) → **«после»** (is after) → переменная **«Изменённая дата»**
     (Adjusted Date). Именно «Дата создания»: фильтр «Дата съёмки» (Date Taken) с переменной не работает.
   - Фильтр «Тип медиафайла» (Media Type) → «Изображение» (Image). На iOS 26 он может не срабатывать —
     тогда видео отсеет сервер на шаге 10.
   - **Сортировка**: «Дата создания», **порядок**: «Сначала старые» (Oldest First).
   - **Ограничить**: включить, **100**.

7. Значения задания — в переменные. Для каждой строки: **«Получить значение словаря»** (ключ, вход —
   «Содержимое URL» из шага 4), затем **«Задать переменную»** (Set Variable). Где написано «текст» — нажмите
   на «Значение словаря» в «Задать переменную» и выберите тип **«Текст»**.

   | ключ     | переменная       |
   |----------|------------------|
   | `mode`   | `Режим` (текст)  |
   | `upload` | `Куда`           |
   | `check`  | `Проверка`       |
   | `size`   | `Размер` (текст) |
   | `thumb`  | `Обложка размер` (текст) |
   | `done`   | `Конец`          |

**Каждый снимок**

8. **«Повторить с каждым»** (Repeat with Each), вход — **«Фото»** из шага 6. Шаги 9–12 — **внутри**
   повтора, перед «Закончить повтор» (End Repeat).

9. Подробности снимка. Четыре раза **«Получить подробности об изображениях»** (Get Details of Images)
   у «Повторяемый объект» (Repeat Item), после каждого — **«Задать переменную»**:
   - «Дата съёмки» (Date Taken) → **«Форматировать дату»** (Format Date): **ISO 8601**, «Включить время» — вкл.
     → переменная `Снято`;
   - «Дата создания» (Creation Date) → «Форматировать дату», так же → переменная `Создано`;
   - «Тип медиафайла» (Media Type) → переменная `Тип`;
   - «Это снимок экрана» (Is a Screenshot) → переменная `Скриншот`.

10. Спросить сервер: **«Получить содержимое URL»**
    - URL: переменная `Проверка`; метод **POST**; заголовок `Authorization` → «Текст» (шаг 1).
    - Тело запроса: **Форма** (Form), четыре текстовых поля: `taken` → `Снято`, `created` → `Создано`,
      `type` → `Тип`, `shot` → `Скриншот`.
    - Затем **«Получить значение словаря»**: ключ `do` (тип — «Текст»).
    - **«Если»**: «Значение словаря» **«является»** (is) `stop` → внутрь **«Остановить эту команду»**
      (Stop This Shortcut). Удалите «Иначе», если оно добавилось.

11. **«Если»**: то же «Значение словаря» **«является»** `send`. Всё, что ниже, до шага 12, — внутри этого «Если»:
    - **«Если»**: `Режим` · **«является»** · `doc`.
      Между «Если» и «Иначе»: **«Получить переменную»** (Get Variable) → «Повторяемый объект».
      Между «Иначе» и «Конец если»: **«Конвертировать изображение»** (Convert Image) «Повторяемый объект» →
      **JPEG**, «Сохранить метаданные» — вкл.; затем **«Изменить размер изображения»** (Resize Image):
      «Конвертированное изображение», ширина — переменная `Размер`, высота — «Авто».
    - После «Конец если»: **«Задать переменную»**: имя `Файл`, значение — **«Результат „Если“»**.
    - Обложка: **«Изменить размер изображения»** «Повторяемый объект» → ширина `Обложка размер` × «Авто»;
      **«Конвертировать изображение»** «Изменённое изображение» → **JPEG**;
      **«Задать переменную»**: имя `Обложка`, значение — «Конвертированное изображение».
    - **«Получить содержимое URL»**: URL — переменная `Куда`; метод **POST**; заголовок `Authorization` →
      «Текст». Тело — **Форма**, пять полей:
      - Текст `mode` → `Режим`;
      - Файл `file` → `Файл` (в поле «Файл» выбирайте через «Переменные…» в меню);
      - Файл `thumb` → `Обложка`;
      - Текст `taken` → `Снято`;
      - Текст `created` → `Создано`.
      Поля «Файл» после выбора могут выглядеть пустыми — это особенность показа, значение там есть.
    - **«Получить значение словаря»**: ключ `error`; **«Если»** «Значение словаря» **«имеет любое значение»** →
      **«Остановить эту команду»**.

**В конце**

12. После «Закончить повтор»: **«Получить содержимое URL»**: URL — переменная `Конец`; метод **POST**;
    заголовок `Authorization` → «Текст».

13. Последним — действие **«Ничего»** (Nothing). Без него при запуске кнопкой «Загрузить сейчас» iPhone
    спрашивает, можно ли передать результат (`{"ok":true}`) обратно.

Проверьте: сделайте снимок и нажмите ▶︎. В первый раз iPhone спросит, можно ли отправлять фото на адрес
сервера, — **«Разрешать всегда»** (Always Allow). Снимок должен появиться в чате с ботом и в галерее, а в
«Автозагрузке с iPhone» у последнего запуска — «завершён».

Если что-то не так, временно поставьте **«Показать результат»** (Show Result) после шага 4 — увидите ответ
сервера — или после шага 6 — увидите, какие фото нашлись.

## Запускайте автоматически

Вкладка **«Автоматизация»** → **«+»** → **«Приложение»** → **«Telegram»** → отметьте **«Открыто»** →
**«Запускать сразу»** → **«Далее»** → **«Новая пустая автоматизация»** → действие **«Запустить команду»**
(Run Shortcut) → **«Фото в Telegram»**.

Срабатывает каждый раз, когда вы открываете Telegram. Телефон в этот момент разблокирован, а время удалить
лишние снимки после съёмки остаётся. По мобильной сети команда ничего не грузит, пока включено «Только по Wi‑Fi»
(см. ниже). Новые снимки проверяются раз в 12 часов, чтобы не нагружать телефон: если запуск ничего нового
не привёз, следующие 12 часов команда ничего не ищет, и ручной запуск тоже. Чтобы не ждать, нажмите в галерее
**«…» → «Автозагрузка с iPhone» → «Загрузить сейчас»**: кнопка снимет паузу и сразу запустит команду (iPhone
спросит, открыть ли «Команды»). Для этого команда должна называться именно «Фото в Telegram».

У старой команды (версии 1) Wi‑Fi проверяла сама автоматизация: перед «Запустить команду» стояли «Получить
сведения о сети» и «Если». С командой версии 2 они не нужны — их можно удалить.

## Настройки в галерее

**«…» → «Автозагрузка с iPhone» → «Настройки»**:

- **Оригиналы без сжатия.** Выключено — телефон сжимает фото в JPEG до 2560 px, как обычные фото
  в Telegram. Включено — фото уходит файлом в исходном качестве (HEIC) вместе с маленькой обложкой.
  Оригиналы больше 20 МБ в галерее открываются только обложкой (целиком — в чате с ботом), а файлы больше
  50 МБ Telegram от ботов не принимает.
- **Загрузить старые фото.** Команда пройдёт всю галерею iPhone по порядку, от самых старых снимков,
  по 100 фото за запуск. Сначала идут новые снимки, а когда новых нет — старые. Сервер видит это по прошлому
  запуску: если он ничего не привёз, следующий берёт старые фото. Старые фото паузы не ждут: пока архив не
  закончен, каждый запуск везёт следующую порцию, а новые снимки проверяются раз в 12 часов.
  Чтобы быстрее, поставьте телефон на зарядку, подключите Wi‑Fi, отключите автоблокировку на это время
  и запускайте команду вручную несколько раз. Прогресс виден там же. 10 000 фото — это несколько вечеров.
- **Только по Wi‑Fi** (включено). По мобильной сети фото не уходят — кроме запуска сразу после «Загрузить
  сейчас». Выключите, если безлимитный интернет. Работает с командой версии 2: она сообщает серверу, через
  какую сеть подключена.

Снимки iPhone по умолчанию в формате **HEIC**. Он вдвое легче JPG, но целиком открывается только на iPhone
и Mac. Если это мешает, переключите камеру на JPG: «Настройки» → «Камера» → «Форматы» → «Наиболее совместимый».

## Насколько это надёжно

- Каждый день для обычных 10–50 фото — обычно без проблем.
- **Заблокированный телефон.** На заблокированном экране iPhone прерывает команду: уходит часть снимков,
  а появляется ошибка про разрешения или потерянную сеть. Поэтому автоматизация запускается при открытии
  Telegram, а не на зарядке. Не блокируйте телефон, пока идёт отправка.
- **Много фото сразу** (например, после поездки). За раз уходит до 100 фото. Остальные догрузятся при
  следующих запусках, или запустите команду вручную несколько раз.
- **«Оптимизация хранилища» iCloud.** Если оригиналы хранятся в iCloud, команде придётся сначала их
  скачать — это медленнее, иногда команда не успевает.
- **Фото со старой датой съёмки** (присланные кем-то, сохранённые из интернета) могут не попасть: команда
  ищет фото новее последнего загруженного. Их загрузите вручную кнопкой «+» в галерее.
- **iPhone зависает на каком-то снимке** (бывает с видео, которые пропустил фильтр, и с повреждёнными файлами).
  Команда версии 2 перед каждым снимком отмечается на сервере. Если два запуска подряд взяли один и тот же
  снимок и ни один его не прислал, сервер дальше его пропускает, а бот пишет его дату — нужный снимок можно
  добавить вручную кнопкой «+». Список пропущенных виден в «Автозагрузке с iPhone».
- **Архив застрял** (у старой команды, без проверки снимков). Больше суток без движения — бот напишет об этом,
  а в галерее можно продолжить архив с более поздней даты.
- Обновления iOS иногда меняют поведение «Команд». Если автозагрузка замолчала, загляните в галерею:
  **«…» → «Автозагрузка с iPhone»** — там видно, когда был последний запуск.

## Безопасность ключа

- Ключ хранится только в вашей команде. На сервере лежит не сам ключ, а его отпечаток (хэш).
- По ключу можно только добавлять фото в ваш чат. Смотреть, удалять или скачивать по нему нельзя.
- Не делитесь командой с ключом внутри (как поделиться без ключа — ниже). Если ключ мог утечь, нажмите «Создать новый ключ» — старый сразу
  перестанет работать. Новый нужно вставить в команду: проще всего удалить её и добавить заново кнопкой
  «Подключить заново» — загрузка продолжится с того же места.

## Для владельца бота: готовая команда ссылкой

Чтобы другим не собирать команду самим, соберите её один раз и поделитесь ссылкой iCloud. Ключ в неё
не попадёт: вместо него iPhone при добавлении спросит каждого его собственный ключ.

1. Соберите и проверьте команду по разделу «Собрать команду самому».
2. В «Командах» нажмите и подержите её → **«Дублировать»**. Дальше работайте с **копией** — в вашей
   команде ключ остаётся.
3. Откройте копию. В действии **«Текст»** (шаг 1) сотрите ключ и напишите `Key ВСТАВЬТЕ_КЛЮЧ`.
   Это важно: текст, который останется в поле, увидят все, кто добавит команду.
4. Добавьте вопрос при добавлении: **ⓘ** внизу экрана → **«Import Questions»** (Вопросы при импорте) →
   **«Add New Question»** → нажмите на поле в действии «Текст». **Question Text:**
   `Вставьте ключ из галереи (он уже скопирован)`. Поле **Default Answer** сотрите — пусть будет пустым:
   тогда человек просто нажмёт «Вставить». Вернитесь назад и проверьте, что вопрос остался в списке
   (иногда он пропадает с первого раза). Если ключ всё же вставят рядом с заглушкой, сервер его найдёт.
5. Переименуйте копию в **«Фото в Telegram»** (если у вас уже есть команда с этим именем, имя можно
   сделать любым — главное, чтобы автоматизации у людей выбирали её).
6. Нажмите и подержите копию → **«Поделиться»** → **«Скопировать ссылку iCloud»**. Если такого пункта нет,
   включите «Настройки» → «Команды» → «Синхронизация iCloud».
7. Ссылка выглядит так: `https://www.icloud.com/shortcuts/…`. Впишите её в `src/screens.js`
   (`SHORTCUT_LINK = '…'`) и выложите сайт — в галерее появится кнопка «Добавить команду».
   Копию после этого можно удалить: ссылка продолжит работать.

Проверьте ссылку на себе: «Подключить заново» → «Добавить команду» → iPhone должен спросить ключ.

Если позже понадобится поменять саму команду, сделайте новую ссылку и замените её. Если новая команда
сообщает серверу другую версию (`v=` в адресе задания), поменяйте и `SHORTCUT_VERSION` рядом со ссылкой:
у кого команда старее, галерея предложит её обновить. Уже добавленные у людей
команды продолжат работать: всё, что сервер может решить сам, он решает сам.
